📖 Documentation des Endpoints
GET/api/chat?query=Hello&model=openai&system=...
Chat texte — retourne JSON. 24 modèles gratuits disponibles.
GET/api/image?prompt=A+cat&model=flux&width=1024&height=1024
Génère image → retourne binaire direct (image/jpeg). Utilisable dans <img src>. flux et zimage sont 100% gratuits.
GET/api/image?prompt=Edit+this&model=nanobanana-pro&imgurl=https://...&width=1024&height=1024
Édition image-to-image. Paramètre imgurl = image source. nanobanana-pro = meilleur modèle d'édition (nécessite clé Pollen).
GET/api/search?query=Latest+AI+news&model=perplexity-fast
Recherche web temps réel. Modèles gratuits : perplexity-fast, perplexity-reasoning, gemini-search, gemini-fast, polly.
GET/api/openai?query=Hello&uid=3&model=gemini-fast&imgurl=https://...
Endpoint unifié. Vision activée si imgurl fourni. Le serveur récupère l'image → base64 → envoi inline.
GET/api/models
Liste complète de tous les modèles avec métadonnées.
🌸 À propos de Pollinations.ai

Pollinations.ai est une plateforme d'IA générative open-source basée à Berlin, Allemagne.
Elle fournit un accès gratuit à des modèles de génération de texte, d'images, d'audio et de vidéo.

• Site : pollinations.ai
• GitHub : github.com/pollinations/pollinations
• API Docs : enter.pollinations.ai/api/docs
• Base URL : https://text.pollinations.ai / https://image.pollinations.ai
• Modèles payants : via enter.pollinations.ai (Pollen credits, $1 ≈ 1 Pollen)
