📚 Intégration — 3 endpoints disponibles
GET
/api/img?url=…&prompt=…

Image distante → image brute. Utilisable directement dans <img src="…">

// Afficher dans une <img>
const src = `/api/img?
 url=${encodeURIComponent(imgUrl)}
 &prompt=${encodeURIComponent(p)}`;
img.src = src; // direct ✅
POST
/api/img (JSON)

Envoie URL ou base64. Retourne JSON avec dataUrl

const r = await fetch("/api/img",{
 method:"POST",
 headers:{"Content-Type":"application/json"},
 body:JSON.stringify({
  prompt:"change le fond",
  imageUrl:"https://…"
 })
});
const {dataUrl} = await r.json();
POST
/api/img/upload (FormData)

Upload fichier local. Retourne l'image brute directement.

const fd = new FormData();
fd.append("file", input.files[0]);
fd.append("prompt","change le fond");

const r = await fetch(
 "/api/img/upload",
 {method:"POST",body:fd}
);
const blob = await r.blob(); // ✅
