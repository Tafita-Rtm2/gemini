📖 Documentation des Endpoints
GET/api/chat?query=Hello&model=openai&system=...
Chat texte via gen.pollinations.ai (OpenAI-compat). Retourne JSON avec response.
GET/api/image?prompt=A+cat&model=flux&width=1024&height=1024
Génère image → retourne binaire (image/jpeg). Utilisable dans <img src>. 8 modèles gratuits !
GET/api/image?prompt=Edit&model=kontext&imgurl=https://...&width=1024&height=1024
Édition image-to-image. kontext GRATUIT !
GET/api/video?prompt=A+sunset&model=ltx-2&duration=5&aspectRatio=16:9
Génère vidéo → retourne video/mp4. Gratuits : ltx-2, nova-reel. Timeout 5min.
GET/api/audio?text=Hello&voice=nova&model=elevenlabs
TTS → audio/mpeg. Utilisable dans <audio src>. 22 voix disponibles.
GET/api/music?prompt=Upbeat+pop&model=elevenmusic&duration=30
Génération musicale → audio/mpeg. elevenmusic (studio) ou acestep (paroles).
GET/api/search?query=Latest+AI+news&model=perplexity-fast
Recherche web temps réel.
GET/api/openai?query=Hello&uid=3&model=openai&imgurl=https://...(opt)
Endpoint unifié. Vision activée si imgurl fourni.
GET/api/models
Liste complète texte + image + vidéo + audio avec métadonnées JSON.
🔑 Débloquer TOUS les modèles — Clé Pollen GRATUITE
1. Va sur enter.pollinations.ai → crée un compte (GitHub OAuth)
2. Génère une clé publiable (pk_...) dans Keys
3. Sur Render.com → Environment → POLLEN_KEY = pk_ta_cle
4. Redéploie → Claude Sonnet, Gemini Pro, Veo, Seedance... débloqués !
