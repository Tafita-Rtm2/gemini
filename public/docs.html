AIVERSE en 5 minutes

Tout ce qu'il faut savoir pour utiliser et intégrer AIVERSE

1 / 6 — Introduction

Qu'est-ce que AIVERSE ?

AIVERSE est un assistant IA multimodal entièrement gratuit qui ne nécessite aucune clé API. Il permet de chatter avec de nombreux modèles IA, de générer des images, d'analyser des photos et de les modifier — le tout depuis votre navigateur ou intégré dans votre propre site web.

Aucune inscription requiseOuvrez l'app et commencez immédiatement.
100% gratuitPas de limite d'utilisation, pas de carte bancaire.
API REST intégréeIntégrez AIVERSE dans n'importe quel site web ou application.
2 / 6 — Installation

Démarrer en 3 commandes

Clonez ou téléchargez le projet, installez les dépendances et lancez :

# 1. Téléchargez le projet git clone https://github.com/votre-repo/aiverse.git cd aiverse # 2. Installez les dépendances npm install # 3. Démarrez le serveur npm start # L'app est accessible sur : https://fitadiavambola-tena-izy-amzay-1-gylo.onrender.com
Node.js 18+ requis.Aucun fichier .env n'est nécessaire — l'app fonctionne sans configuration.
3 / 6 — Chat IA

Utiliser le Chat

Sélectionnez un modèle dans le menu déroulant, tapez votre message et appuyez sur Entrée. L'historique de conversation est conservé en mémoire. Cliquez sur "Nouveau chat" pour recommencer.

Mistral Large GPT-4o Gemini 2.0 Claude Llama 3.3 70B DeepSeek-V3 DeepSeek-R1 Qwen-Max Phi-4 SearchGPT 🌐

Tous les modèles ci-dessus sont gratuits et sans clé API.

4 / 6 — Génération d'images

Créer des Images par IA

Allez dans Générer Image, décrivez l'image souhaitée en français ou en anglais, sélectionnez le modèle et la taille, puis cliquez sur "Générer l'Image". Vous pouvez télécharger le résultat.

# Exemples de prompts efficaces : "Un chat astronaute sur la lune, style photoréaliste" "Paysage de montagne au coucher de soleil, peinture à l'huile" "Logo minimaliste pour une startup tech, fond blanc" "Portrait d'une femme afro-futuriste, cyberpunk, 8K"
5 / 6 — Analyse d'images

Analyser & Éditer des Photos

Analyser : Importez une image, posez une question optionnelle, et l'IA Vision décrit ce qu'elle voit en français.

Éditer : Importez une image, décrivez la modification voulue. L'IA analyse d'abord votre image, puis génère une nouvelle version modifiée selon vos instructions.

6 / 6 — Intégration

Intégrer dans votre Site

AIVERSE expose une API REST complète. Intégrez le chat IA dans n'importe quel site ou application en quelques lignes de JavaScript, sans clé API.

// Chat depuis n'importe quel site web const response = await fetch('https://fitadiavambola-tena-izy-amzay-1-gylo.onrender.com/api/chat', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ message: 'Bonjour, comment vas-tu ?', model: 'mistral' }) }); const data = await response.json(); console.log(data.message); // Réponse de l'IA

Intégration dans votre site web

Intégrez AIVERSE dans n'importe quel site via iframe ou directement via l'API REST avec fetch. Aucune clé API n'est requise.

Option 1 — Intégrer via iframe
<iframe src="https://fitadiavambola-tena-izy-amzay-1-gylo.onrender.com" width="100%" height="600" frameborder="0" style="border-radius: 12px; box-shadow: 0 4px 20px rgba(0,0,0,.1);" ></iframe>
Option 2 — API Fetch (JavaScript)
// Chat IA — sans clé API async function chatWithAI(message, model = 'mistral') { const res = await fetch('https://fitadiavambola-tena-izy-amzay-1-gylo.onrender.com/api/chat', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ message, model }) }); const data = await res.json(); return data.message; } // Génération d'image async function generateImage(prompt) { const res = await fetch('https://fitadiavambola-tena-izy-amzay-1-gylo.onrender.com/api/generate-image', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ prompt, model: 'flux' }) }); const blob = await res.blob(); return URL.createObjectURL(blob); // URL de l'image }
