📚 Documentation

🤖 Chat & Conversation

  • Description: Discutez avec l'IA sur n'importe quel sujet
  • Modèle: Mistral-7B-Instruct
  • Capacités: Q&A, Rédaction, Analyse, Coding
  • Historique: Jusqu'à 50 messages mémorisés

✨ Génération d'Images

  • Modèle: Stable Diffusion 3.5 / FLUX.2
  • Résolution: 256px à 1024px
  • Format: PNG haute qualité
  • Temps: 30-60 secondes par image

✏️ Édition d'Images

  • Modèle: Qwen-Image-Edit-2511
  • Support: Inpainting, Suppression, Style Transfer
  • Format: PNG, JPG (max 10MB)
  • Précision: Très haute fidélité

🔍 Analyse d'Images

  • Modèle: Vision Transformer (ViT)
  • Détecte: Objets, Catégories, Contenu
  • Format: Tous les formats d'image
  • Temps: < 5 secondes

⚙️ Configuration

  • API Key: Hugging Face Token requis
  • Rate Limit: Sans limite pour les modèles gratuits
  • Storage: Conversions en mémoire
  • Sécurité: CORS activé, Validation côté serveur

🚀 Conseils & Astuces

  • Utilisez des prompts détaillés pour de meilleurs résultats
  • Spécifiez le style (photorealistic, digital art, etc.)
  • Mentionnez l'éclairage et l'ambiance
  • Pour l'édition, décrivez précisément les changements

🔌 API Endpoints

POST /api/chat

Envoyer un message et recevoir une réponse IA

{ "message": "Bonjour, comment vas-tu?", "conversationId": "conv_123", "systemPrompt": "Tu es un assistant..." }

POST /api/generate-image

Générer une image à partir d'un texte

{ "prompt": "Un chat", "height": 512, "width": 512, "numSteps": 20, "guidanceScale": 7.5 }

POST /api/edit-image

Éditer une image existante (multipart/form-data)

FormData: - image: (file) - prompt: "Changez la couleur..." - strength: 0.75

POST /api/analyze-image

Analyser le contenu d'une image

FormData: - image: (file) Response: { "classifications": [...], "imageSize": 123456, "uploadedAt": "2024-01-01..." }

GET /api/conversation/:id

Récupérer l'historique d'une conversation

Response: { "id": "conv_123", "messages": [...], "createdAt": 1234567890 }

GET /api/health

Vérifier l'état du serveur

Response: { "status": "OK", "timestamp": "2024-01-01...", "uptime": 3600 }

🐍 Python Example

import requests response = requests.post( "http://localhost:5000/api/chat", json={"message": "Bonjour"} ) print(response.json())

🔗 cURL Example

curl -X POST http://localhost:5000/api/chat \ -H "Content-Type: application/json" \ -d '{"message":"Bonjour"}'
